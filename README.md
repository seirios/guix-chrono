# Guix packages for projectCHRONO

This repository is a Guix channel providing the following packages:

+ `projectCHRONO` with modules enabled:
  + `HDF5`
  + `FSI_SPH`
  + `MULTICORE`
  + `POSTPROCESS`
  + `SENSOR`
  + `VEHICLE`

+ `projectCHRONO-vsg` with modules enabled:
  + `HDF5`
  + `FSI_SPH`
  + `MULTICORE`
  + `POSTPROCESS`
  + `SENSOR`
  + `VEHICLE`
  + `VSG`

The specific version dependencies for module `VSG` are also defined as packages.
